Auxiliar de Programação

Programação de pesquisa

ℹ️ Como usar
  1. Use a ferramenta de polígono/retângulo (canto sup. dir. do mapa) para selecionar vários trechos de uma vez — ou toque em trechos avulsos.
  2. Escolha o geofonista e toque em Vincular. Para tirar, selecione e toque em Desvincular.
  3. ✕ Limpar seleção (no mapa) zera a seleção atual.
  4. Na lista Programação por geofonista, toque num nome para ver só a rota dele; ‹ Ver toda a rede volta.
  5. Sem pesquisa desde ‹data›: mostra só trechos não pesquisados desde a data (candidatos a reprogramar).
  6. Conforme o campo lança os traçados, os trechos viram pesquisado e saem da lista de pendências.
